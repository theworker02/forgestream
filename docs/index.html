Overview

Forge encode/decode helpers for stream payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/forgestream.git
cd forgestream
node src/cli.js --help
node --test
